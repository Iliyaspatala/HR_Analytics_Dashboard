# HR Analytics Dashboard Using Power BI

## Project Overview

Analyzed HR employee attrition data using Power BI to identify patterns and insights on workforce trends.

## Dataset

- Source: Kaggle - IBM HR Analytics Employee Attrition
- Records: 1,470 employees
- Features: 35 columns

## Key Findings

- Overall Attrition Rate: 16.12%
- Sales Executives have the highest attrition count
- Attrition is highest in the age group 28–35
- Average Monthly Income: $6,502
- R&D is the largest department with ~961 employees

## Tools Used

- Power BI Desktop
- DAX (Data Analysis Expressions)
- Power Query
